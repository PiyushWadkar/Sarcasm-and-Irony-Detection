# Evaluation Reports Directory

This directory stores evaluation metrics, cross-validation records, and performance benchmark summaries generated by `train_model.py`.

## Files
- **`evaluation_summary.json`**: Contains full test set evaluation metrics on the official SemEval-2018 Task 3 Subtask B benchmark:
  - Accuracy
  - Macro Precision
  - Macro Recall
  - Macro F1-Score
  - Per-Class Precision, Recall, F1, and Support
  - Confusion Matrix array
  - Model comparison breakdown between Logistic Regression and Calibrated Linear SVM
